## Featured Projects

### [GAM 2.1.0](https://github.com/slauf82/gam_standalone)

Modernization of a long-established administration and invoicing system using Java, Spring Boot, React, TypeScript and MariaDB.

Combines business workflows, invoicing, cancellation and credit-note logic, PDF and ZUGFeRD processing, role-based access control, TOTP and passkeys with multi-source device discovery and inventory.

Supports Windows, Linux and macOS locally and remotely, plus Android and iOS/iPadOS via USB and Wi-Fi. Consolidates information from multiple discovery sources into consistent device identities.

**Status:** Version 2.1.0 released and successfully tested on physical hardware.

### [MOH Offline](https://github.com/slauf82/moh_offline)

Fully offline clinical workflow and documentation application focused on ENT workflows. Modernizes existing medical business logic while preserving established processes and reducing proprietary platform dependencies.

**Status:** Functional offline application; further improvements planned.

### [Felicity API](https://github.com/slauf82/felicityAPI)

Home Assistant integration for Felicity Solar inverter and battery systems, providing access to device and operating data.

**Status:** Operational and under continued development.

### [Koplenti ACStorage](https://github.com/slauf82/koplenti_acstorage)

Local PV battery control combining Home Assistant automation with hardware integration for Kostal ACStorage systems.

Focuses on coordinated inverter control, charging and discharging strategies, PV surplus utilization and state synchronization.

**Status:** Actively used in production.

### [Appliance State Reconstruction](https://github.com/slauf82/appliance-state-reconstruction)

Framework for reconstructing reliable device states from incomplete, delayed or inconsistent data sources.

Applies event-driven processing, state machines, recovery mechanisms and synchronization to practical Home Assistant monitoring and automation.

**Status:** Actively used in production.

### [EseeCloud PTZ](https://github.com/slauf82/ha_esee_cloud)

Home Assistant integration for local pan and tilt control of EseeCloud/Jennov cameras through the recorder.

Implements the vendor-specific WebSocket protocol in asynchronous Python, with channel-specific movement commands, continuous movement, stop control and session management.

**Status:** Actively used with physical cameras in daily operation.
